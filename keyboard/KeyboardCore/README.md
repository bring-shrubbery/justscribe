# KeyboardCore

The keyboard engine behind the JustScribe keyboard: layouts, keys, callouts, gestures, the
autocomplete toolbar and `KeyboardInputViewController`.

It is derived from the MIT-licensed source of KeyboardKit 9.9.1. That license is in `LICENSE`
and has to stay with this code. The paid-feature placeholders, the license gate and the
branding have been removed, and the remaining code is maintained here as part of JustScribe.
